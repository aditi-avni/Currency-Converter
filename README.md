# Currency Converter

A simple and interactive Currency Converter built using HTML, CSS, and JavaScript.

This project was created to practice JavaScript concepts like DOM manipulation, API fetching, asynchronous programming, event handling, and dynamic UI updates.

---

## Features

- Real-time currency conversion
- Live exchange rates using API
- Dynamic country flags
- Default currency selection (USD → INR)
- Automatic exchange rate updates
- Input validation
- Clean and responsive UI

---

## Tech Stack

- HTML
- CSS
- JavaScript

---

## Concepts Practiced

- DOM Manipulation
- Event Listeners
- Async/Await
- Fetch API
- Loops
- Dynamic Element Creation
- Template Literals
- Object Access
- Form Handling

---

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser
